# عائلة دلول

مشروع Vue 3 عربي ومتجاوب لتسجيل وإدارة بيانات العائلات والأفراد والاحتياجات.

## التشغيل

1. ثبّت Node.js إصدار 22 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. نفّذ `npm install`.
4. انسخ ملف `.env.example` إلى ملف جديد باسم `.env.local`، ثم ضع فيه رقم هوية المدير وكلمة المرور.
5. نفّذ `npm run dev`.
6. افتح الرابط المحلي الذي يظهر في Terminal.

إذا كان المشروع يعمل محليًا قبل تعديل `.env.local`، أوقفه ثم شغّله من جديد حتى تُقرأ بيانات الدخول.
أبقِ كلمة المرور بين علامتي الاقتباس، خصوصًا إذا كانت تحتوي على الرمز `#`.

## إنشاء نسخة جاهزة للنشر

نفّذ `npm run build` وستظهر الملفات الجاهزة داخل مجلد `dist`.

## ربط Google Sheets

استخدم الملفات الموجودة داخل مجلد `google-apps-script` واتبع ملف **تعليمات-الربط.md**. بعد نشر Google Apps Script، ألصق رابط Web App من صفحة إعدادات الإدارة داخل الموقع.

بيانات دخول الإدارة تُحفظ كأسرار على الخادم ولا توجد كلمة المرور داخل كود الواجهة.
